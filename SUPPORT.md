# Support

BongoPay is pre-1.0 (see [ROADMAP.md](ROADMAP.md)). Support channels are intentionally minimal
right now.

## Getting Help

- **Usage questions / "how do I...":** Open a GitHub Discussion if enabled, otherwise open an
  issue using the closest-fitting template in
  [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/).
- **Bug reports:** Use the [Bug report](.github/ISSUE_TEMPLATE/bug_report.yml) template.
- **Feature requests:** Use the [Feature request](.github/ISSUE_TEMPLATE/feature_request.yml)
  template.
- **Provider requests:** Use the [Provider request](.github/ISSUE_TEMPLATE/provider_request.yml)
  template.
- **SDK requests:** Use the [SDK request](.github/ISSUE_TEMPLATE/sdk_request.yml) template.
- **Documentation issues:** Use the
  [Documentation improvement](.github/ISSUE_TEMPLATE/documentation.yml) template.
- **Architectural proposals:** See the [RFC process](rfcs/README.md) rather than a support
  request.
- **Security vulnerabilities:** Do **not** use a public issue — see [SECURITY.md](SECURITY.md).

## Response Expectations

This is a community-driven, early-stage open-source project without a support SLA. Maintainers
triage issues on a best-effort basis; see [GOVERNANCE.md](GOVERNANCE.md) for maintainer roles.

## Not a Support Channel

BongoPay does not, and will not for the foreseeable future, process real payments — do not
report incidents about real money movement, real provider outages, or production financial
issues here (see [ROADMAP.md](ROADMAP.md) §"What NOT to Build Yet").
