# docs/contributing/ — Extended Contribution Guidance

Longer-form contribution guidance that doesn't fit in the root [CONTRIBUTING.md](../../CONTRIBUTING.md)
without making that file unwieldy — for example, a walkthrough of a first contribution, or
area-specific onboarding beyond what a directory's own README covers.

## Status

**Empty.** [CONTRIBUTING.md](../../CONTRIBUTING.md),
[AGENTS.md](../../AGENTS.md), and
[.github/CONTRIBUTING_AGENT.md](../../.github/CONTRIBUTING_AGENT.md) currently cover the full
contribution workflow for both human and AI-agent contributors. A document belongs here only
once one of those becomes too long to stay readable — not preemptively.
