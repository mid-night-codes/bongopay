## Becoming a Maintainer

See [GOVERNANCE.md — Maintainer Nomination](GOVERNANCE.md#maintainer-nomination). In short:
sustained, high-quality contribution and review activity, nominated by an existing Core
Maintainer.

## Area Ownership

Area-level ownership (which Maintainer reviews which paths) is enforced via
[.github/CODEOWNERS](.github/CODEOWNERS), which is the operational source of truth for "who
reviews what." This file is the human-readable roster; CODEOWNERS is what GitHub actually
enforces.
