# docs/maintainers/ — Maintainer-Facing Process Docs

Process documentation for people holding a Maintainer or Core Maintainer role per
[GOVERNANCE.md](../../GOVERNANCE.md) — release mechanics, issue/PR triage conventions, and
security response coordination — as distinct from [MAINTAINERS.md](../../MAINTAINERS.md), which
is just the roster.

## Status

**Empty.** With a single founding Core Maintainer (see [MAINTAINERS.md](../../MAINTAINERS.md))
and a lightweight, manual release process (see
[VERSIONING.md](../../VERSIONING.md#release-process-current-state)), there is no undocumented
process yet to write down. A doc belongs here once the maintainer team grows beyond one person
and an informal process needs to become an explicit one.
